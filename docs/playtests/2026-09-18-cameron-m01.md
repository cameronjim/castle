## Cameron's report
- "Characters don't die when I kill them." Log confirms: zero guard deaths from gunfire. Both
  deaths were takedowns. The three infirmary guards were never killed.
- "All you can do is run around." Guards never moved: log shows "Unable to find RecastNavMesh
  instance" on every map load. Nav mesh was never generated.
- Default mouse sensitivity too high.
- Wants a small green four-bar crosshair with a centre gap.
- Wants to see Frank's hands: pistol in hand when armed, fists when not.
- Guards should look like creepy security / riot cops, not grey mannequins.
- Pistol and keycard pickups don't read as a pistol or a keycard.
- Room should be dark with deliberate lighting. "It should look professional."
- Direction: perfect one room at a time. Focus on the cell and first corridor before
  anything else.

## Top five problems, in order
1. Bullets do no damage to guards (blocking bug).
2. Guards can't path, so there is no stealth or combat (blocking bug).
3. No first-person body: no hands, no gun, no feedback on fire.
4. Everything is grey boxes in daylight; nothing reads as a prison.
5. Sensitivity too high; crosshair is a placeholder.

## What worked
- The full loop runs: takedown, loot, door, objectives, end card, flashback, all fire in order.
- Takedown prompt and pickup interaction were understood without instruction.

## Numbers
- Total time: 1:42 (target is 8 to 12 minutes; the level is far too short and empty once guards work)
- Deaths: 0
- Takedowns: 2
- Guards alerted before the first shot: unknown (guards couldn't move; alert states not logged)

## Actions
- Fix bullet damage with a world test that reproduces it.
- Runtime nav mesh generation in project settings; smoke test asserts guards move.
- LookSensitivity property, default 0.45.
- Four-bar green crosshair, hit-marker flash, hidden when unarmed.
- First-person arms and pistol viewmodel, procedural recoil and reload.
- Guards: idle/walk anim via animation assets, black tactical materials, red visor, flashlight.
- Cell and corridor 1: ceilings, no daylight, fluorescents (one flickering), red emergency
  light, concrete and steel materials, dressing.
- Pistol and keycard pickups composed from primitives with proper materials.
- Log guard alert state changes so the next playtest can measure stealth.
