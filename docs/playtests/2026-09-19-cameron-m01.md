## Causes found in the log or by inspection
- `LogMaterial: Warning: M_FrankArms / M_GuardBody / M_GuardVisor missing usage flag
  SkeletalMesh! Default Material will be used in game.` The arms and every guard render
  with the default material in the standalone game. Editor screenshot tests never showed
  this because the editor compiles the usage on demand.
- The pitch-black room is corridor 2 and the infirmary: ceilings were added map-wide to
  kill daylight, and those rooms never got lights of their own.
- Gun invisible: suspected soft-pointer viewmodel mesh not loaded in the standalone game,
  or the pickup auto-select path skipping the mesh apply. Editor tests preload assets.
- Backwards walk: mesh yaw relative to movement, or the AI facing logic during patrol.
- Door: interaction sweep probably blocked by art frame props or the slab's collision
  channel.

## Lesson
Editor-process screenshots are not the game. Every visual pass now also has to be
checked from a `-game` run, and the log from that run has to be free of material and
LogCastle warnings.

## Actions
All five fixed in one pass, each with a test or a render as proof. See the next playtest.
